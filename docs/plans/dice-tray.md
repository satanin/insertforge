# Dice Tray — first prototype

- New `dice` tray, initially created through **Add loose tray → Dice Tray**.
- Two modes: individual pockets following each die’s XY silhouette resting on a face, and one shared compartment. Vertical walls allow straight extraction without undercuts. Clearance offsets the contour by half on each side.
- Mixed die groups with independent type, size and count. Columns define a uniform grid sized for the largest die. The shared compartment reserves the full rectangular grid envelope, including unused cells in the final row.
- Measurements copy explicitly from project types or inventory, including mixed groups; manual group/size/type/count changes release assignments.
- Clearance is total, not per side. D6 size is side length; other types scale by maximum vertex distance. D4/D6/D8/D12/D20 use regular polyhedra; d10 uses a symmetric pentagonal trapezohedron. Commercial proportions and rounded edges vary: physical fit needs validation.
- `Exposed die` defaults to 40% of oriented die height (range 10–80%). All individual pockets finish at one common upper plane, set by the greatest retained die height. Smaller dice use raised supports below that plane, preserving each die’s requested exposed fraction. The structural floor thickness and XY layout remain unchanged. The old pocket-depth control is only read for saved legacy millimetre settings. Finger recesses stop at each pocket’s support height.
- A standalone shared tray lowers its perimeter for the shortest die and keeps all dice on the common floor. A shared box has no individual retaining walls and hides the exposure control. In box mode, the full perimeter starts at the structural floor and reaches floor + tallest oriented die + headroom (plus sliding-guide height when required); dimensions and lid are independent of exposure, including legacy millimetre values. The tallest die remains on the structural floor; raised smaller dice stay below its highest point. Without box mode, the common retaining plane can decrease as exposure increases; width/depth stay fixed.
- Box mode extends only the outer perimeter to the highest positioned die + headroom (default 2 mm). A flat object can rest on that perimeter without touching the idealized dice; there is no interlocking stacking connection.
- Optional removable lid implies box mode. Default plate thickness 2 mm, fit clearance 0.3 mm per side, shallow internal locating rim limited to half the headroom, avoiding dice contact. Lid prints with its plate flat and rim upward, and is inverted in assembled preview. Body/lid are separate STL/3MF parts, also after moving the tray into a Box; 3MF follows `group3mf` as usual. Worker supplies body/lid preview; Explode lifts the lid vertically.
- Lid selector also offers Sliding, reusing Box guides along Y. Wall thickness is at least 3 mm (or greater when clearance requires it), and body height reserves wall thickness above dice/headroom for the guides. No elastic latch in this prototype; shared lid helpers accept optional `lockEnabled: false`, preserving defaults for all other models. The lid opens toward +Y; collision tests check the closed pose and intermediate/full opening positions. Explode follows that direction without lifting.
- Lid text: enabled explicitly; blank text follows tray name. Shared style controls offer engraved, flush inlay (up to 0.4 mm) and raised (0.6 mm), with a colour picker. Inlay and raised text export as separate coloured 3MF bodies grouped with the lid, while STL combines them. Text uses the shared accented vector font, 1.2 mm stroke and 128-segment curved strokes; inspect actual slicing before treating text as physically validated. Raised text adds 0.6 mm to assembled height and prints facing up, so supports under the plate may be needed. Engraved/inlay lids retain a flat top and print with the exterior face on the bed.
- Outer radius requests 3 mm on new trays, limited to the wall band to preserve cavities; missing/0 preserves existing saved trays. Editor shows actual applied radius.
- Preview counters displays faceted dice sharing the exact socket orientation, in individual/layer/project views; previews are excluded from printed geometry.
- Fixed height; `autoHeight` is disabled. STL/3MF use the existing worker export pipeline, including `group3mf`.
- Unit checks cover cavity volume and floor retention for all six die types, shared mode, partial rows, validation, persistence and inventory snapshots. Visual/physical user validation pending.

Extraction regression tests intersect real preview polyhedra with the tray at seated and lifted positions (including d10), in both storage modes with all six types and mixed sizes. This checks the geometric path; real dice dimensions/rounding and physical grip remain pending user validation.

Finger recesses: optional round opening at the left of each individual pocket, stopping at its support floor. Diameter defaults to 10 mm on new trays; 0/missing preserves previous layouts. Radius is capped by die size; additional X space preserves outer walls and dividers. Shared mode ignores this setting.

Next iterations: physical lid-fit and stacking validation, compact packing for mixed sizes, and more than one shared compartment.
